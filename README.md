# YouTube to MP3/MP4 Downloader (GUI)

โปรแกรม GUI แบบง่าย สำหรับแปลงไฟล์จาก YouTube URL เป็น **MP3** (เสียงคุณภาพสูงสุด 320kbps) หรือ **MP4** (วิดีโอคุณภาพสูงสุดที่มี) โดยใช้ไลบรารี [yt-dlp](https://github.com/yt-dlp/yt-dlp) ในการดาวน์โหลด และ **ffmpeg** ในการแปลง/รวมไฟล์

## สิ่งที่ต้องติดตั้งก่อนใช้งาน

1. **Python 3.8 หรือใหม่กว่า**
   - Windows/macOS: ดาวน์โหลดจาก [python.org](https://www.python.org/downloads/) (มี tkinter ติดมาให้อยู่แล้ว)
   - Linux (Ubuntu/Debian): `sudo apt install python3 python3-tk`

2. **ffmpeg** (จำเป็นมาก ไม่มีไม่สามารถแปลง/รวมไฟล์คุณภาพสูงสุดได้)
   - Windows: ดาวน์โหลดจาก https://ffmpeg.org/download.html แล้วเพิ่ม path ของ `ffmpeg.exe` ลงใน Environment Variable `PATH`
   - macOS: `brew install ffmpeg`
   - Linux: `sudo apt install ffmpeg`

3. **yt-dlp** (ไลบรารี Python สำหรับดาวน์โหลด)
   ```bash
   pip install -r requirements.txt
   ```
   หรือ
   ```bash
   pip install yt-dlp
   ```

## วิธีใช้งาน

```bash
python yt_downloader_gui.py
```

หน้าโปรแกรมจะมี:

- ช่องให้วาง YouTube URL
- เลือกรูปแบบไฟล์: **MP3** (เสียง 320kbps) หรือ **MP4** (วิดีโอคุณภาพสูงสุด — โปรแกรมจะเลือกภาพและเสียงที่ดีที่สุดแล้วรวมเป็นไฟล์เดียวให้อัตโนมัติ)
- เลือกโฟลเดอร์ที่จะบันทึกไฟล์ (ค่าเริ่มต้นคือโฟลเดอร์ Downloads)
- ปุ่ม "ดาวน์โหลด" พร้อมแถบแสดงความคืบหน้าและ log

## หมายเหตุเรื่องคุณภาพไฟล์

- **MP3**: ดึงเสียงที่คุณภาพดีที่สุดที่ YouTube มีให้ แล้วแปลงเป็น MP3 บิตเรต 320kbps (คุณภาพสูงสุดของไฟล์ MP3)
- **MP4**: yt-dlp จะเลือกสตรีมวิดีโอความละเอียดสูงสุด (เช่น 1080p/4K ถ้ามี) และสตรีมเสียงคุณภาพสูงสุด แยกกัน แล้วใช้ ffmpeg รวมเป็นไฟล์ MP4 เดียว เพราะ YouTube มักแยกไฟล์วิดีโอความละเอียดสูงกับไฟล์เสียงออกจากกัน

## ข้อจำกัดและความรับผิดชอบ

- โปรดใช้ดาวน์โหลดเฉพาะเนื้อหาที่ท่านมีสิทธิ์ใช้งาน เช่น วิดีโอของตัวเอง หรือเนื้อหาที่อนุญาตให้ดาวน์โหลดเพื่อใช้ส่วนตัวตามกฎหมายในประเทศของท่าน การดาวน์โหลดเนื้อหาที่มีลิขสิทธิ์โดยไม่ได้รับอนุญาตอาจขัดต่อข้อกำหนดการใช้งานของ YouTube และกฎหมายลิขสิทธิ์ในบางประเทศ
- YouTube เปลี่ยนแปลงระบบภายในอยู่บ่อยๆ หากโปรแกรมใช้งานไม่ได้ ให้ลองอัปเดต yt-dlp ก่อน:
  ```bash
  pip install --upgrade yt-dlp
  ```
- หากเจอ error "ไม่พบ ffmpeg" ให้ตรวจสอบว่าติดตั้ง ffmpeg และเพิ่มลง PATH เรียบร้อยแล้ว (ลองพิมพ์ `ffmpeg -version` ใน terminal/command prompt เพื่อเช็ค)
